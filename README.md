## <img src="https://img.shields.io/badge/-04-6D28D9?style=flat-square" height="22"/> Featured Projects

<details open>
<summary><b>🚦 AI-Powered Intelligent Traffic Monitoring System</b></summary>
<br/>

Real-time, multi-road vehicle detection and adaptive traffic signal control system, built to demonstrate applied computer vision at city scale.

| | |
|---|---|
| **Stack** | Python, YOLOv8, ByteTrack, Streamlit |
| **Scale** | Expanded from single-road to multi-road, city-wide monitoring |
| **Performance** | Resolved critical vehicle-counting bug; stable real-time inference |
| **Security** | Controlled public demo access via managed ngrok tunneling |
| **Impact** | Adaptive signal timing driven directly by live vehicle density |
| **Repository** | [github.com/Rahim-Kamran](https://github.com/Rahim-Kamran) |

Vehicle detection and multi-object tracking are handled by YOLOv8 combined with ByteTrack, feeding into an adaptive signal-timing layer that reacts to live traffic density instead of fixed timers. The system was iteratively hardened across multiple engineering passes — fixing a critical counting bug, resolving tunneling issues for public demos, and scaling from a single intersection to a multi-road, city-wide monitoring view — before being deployed on Streamlit Community Cloud.

</details>

<details>
<summary><b>🌫️ AQI Prediction System</b></summary>
<br/>

Collaborative machine learning system predicting Air Quality Index across 26 Indian cities, served through a multi-tab analytics dashboard.

| | |
|---|---|
| **Stack** | Python, Scikit-learn, Streamlit, WAQI API |
| **Scale** | 26 Indian cities, live API-backed data |
| **Performance** | Random Forest 97.75% • Decision Tree 96.51% • Logistic Regression 87.95% |
| **Security** | Standard API key handling for live WAQI data |
| **Impact** | Real-time AQI insight using the official CPCB breakpoint formula |
| **Repository** | [github.com/Mehnaz-Bashir](https://github.com/Mehnaz-Bashir) |

Built collaboratively as a foundational ML project, the system benchmarks three classification models against live air-quality data pulled through the WAQI API and converted using the CPCB breakpoint formula. The result is a 7-tab Streamlit dashboard covering prediction, historical trends, and city-wise comparison, with accuracy reporting fixed and hardened for public showcasing.

</details>

<details>
<summary><b>🛠️ Local Service Marketplace</b></summary>

| | |
|---|---|
| **Stack** | Java, Spring Boot, React, JWT, Testcontainers |
| **Scale** | Multi-role platform — CUSTOMER and PROVIDER flows |
| **Performance** | Haversine-based proximity matching for nearby providers |
| **Security** | JWT authentication with role-based access control |
| **Impact** | End-to-end booking state machine validated via Postman + integration tests |
| **Repository** | [github.com/Rahim-Kamran](https://github.com/Rahim-Kamran) |

Reliability was validated through Testcontainers-based integration tests alongside manual Postman testing, with a React frontend layered on top to consume the API end-to-end.
